# Advent V8 交付说明

## 本版修复

- 礼物统计只读取内置元数据、双方索引、已同步缓存与本地未发布记录，按礼物 ID 去重；失败时保留上次成功值并显示缓存状态，不读取未来礼物正文，不产生偷看记录。
- 圣诞书桌整合倒计时、双方礼物堆、四个常用入口、共同书桌与分级操作；礼物堆使用固定八个装饰节点，数量变化只改变层级。
- 页面与浮层使用语义主题变量，补齐夜间输入框、按钮、选中态、滚动条、贴纸库、编辑器、音乐与弹层；房子和手账作品保持独立美术颜色。
- 手账导出改为 Canvas 合成，按预览 DOM 的实际换行绘制文字，加载实际使用字体，导出纸张、标题、正文、胶带、火漆、边框、贴纸与照片；支持 1× / 2× PNG，图片加载失败时中止并报错。
- 图片贴纸保留 `src`、位置、缩放、旋转、透明度与 z 顺序。WebKit 暂存文件改用 ArrayBuffer，避免自动化环境无法写入 Blob/File。
- 五种相纸边框、裁切方式、焦点位置与背面文字在编辑、正式预览、翻转和 PNG 导出间共用同一套布局数据；草稿持久化包含下拉框。
- 编辑器改为四组可折叠表单，加宽桌面布局并保留未保存保护、完整预览、附件和音频操作。
- PAT 默认仅保存在当前标签页；只有主动勾选才明文存入本机 `localStorage`，提供清除按钮，并区分无配置、无效、权限不足、限流和网络失败。发布重新读取远程并核验 ID 后才清除本地暂存。
- 流畅模式减少雪花粒子与装饰动画，后台标签页停止雪花和走动；遵循 `prefers-reduced-motion`。

## 真实公开元数据核验（2026-11-27）

- Spotify track `4cOdK2wGLETKBW3PvgPWqT`：公开 oEmbed 实际返回标题 `Never Gonna Give You Up` 与封面；该响应没有 `author_name`，因此歌手保持为空，不编造歌手信息。
- 网易云歌曲 `185809`：官方 song/detail 接口实际返回《彩虹》/周杰伦/《我很忙》，但响应没有 `Access-Control-Allow-Origin`，浏览器从 GitHub Pages 直连会被 CORS 拦截。当前界面会明确显示网络/接口不可用；未接入匿名第三方代理，也未声称此平台在静态网页中自动识别成功。
- 元数据识别成功不代表播放器可播放；播放可用性仍需在实际播放器中确认。

## 协议与数据边界

保持 `advent-gifts-v3.2`、北京时间解锁、XOR+Base64 payload、双方索引、唯一 ID、封箱与偷看规则。V8 新增字段均为可选；手账图片贴纸统一使用 `src`，不使用 `asset` 代替。`.mockdata/` 与 `.mockgh/` 不进入提交。

## 已知限制

- 网易云官方元数据接口缺少浏览器 CORS 许可，静态 Pages 无法直接自动识别；需要站点方提供同源元数据接口或正式代理后，才能在网页中启用。
- 真实 iPad Safari、Dark Reader 扩展实机效果未验证。
- 未上传或再分发商业字体；导出会检查字体加载并在失败时中止，避免静默缺字。
