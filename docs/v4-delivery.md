# Advent V4 交付说明

## 当前版本与范围

当前代码版本为 `8.2.1`，基于 `main` 分支的 V8 版本迭代；本说明覆盖整体 UI、收藏馆、写入权限和圣诞邮局改造。礼物编码协议仍为 `advent-gifts-v3.2`，既有文件格式、素材、礼物 ID 与 12 月 24/25 日特别结局保持不变。

- 页面与交互：`index.html`、`app.js`、`advent.css`、`house.js`、`music.js`、`stickers.js`。
- 数据与同步：`backend.js`、`config.js`、独立活动源 `gift_events.json`。
- 协议与发布：`README.md`、`docs/advent-v4-protocol.md`、`docs/release-v4.md`。
- 自动化：`tests/v4_archive_e2e.py`、`tests/v8_e2e.py`、`tests/v4_smoke.py`、既有音乐、贴纸、同步和完整 E2E 测试。

## UI 与收藏馆

- 桌面采用小屋与书桌双栏，书桌面板宽度限制在 480–540px；平板横屏保留分栏，平板竖屏与手机自然堆叠。未使用全局 `zoom` 或 `transform` 缩放。
- 编辑器桌面宽度 680–760px，所有浮层最大高度不超过 `88dvh`，内容区独立滚动，底栏固定。
- 主题使用语义变量，夜间为深棕、暖黑与旧纸色；输入框、附件、悬停、焦点和禁用状态继承主题。
- 收藏馆左右分栏：左侧为双方礼物堆与数量，右侧按送礼人、1–25 日、类型、状态和关键词筛选；日期手风琴与礼物详情可独立展开。
- 收藏馆、首页和礼物卡复用同一权威数据投影与 `renderRemoteEntry()` / `renderItem()` 渲染路径，不建立第二份礼物清单。
- 未解锁的对方礼物只显示安全元数据。列表、筛选、搜索和展开不会开启礼物、增加偷看或读取正文/附件；作者本人未解锁的本地礼物仍可在编辑器中回填。

## 日期与写入权限

所有日期判断使用 `Asia/Shanghai`，并在实际写入 API 中再次校验，不仅依赖前端按钮状态。

| 阶段 | 普通礼物写入规则 |
|---|---|
| 12 月 26 日前（含筹备期） | 双方可新增、修改或删除自己尚未正式封存的 1–25 日普通礼物，包括已过去的日期；每天可有多份礼物 |
| 12 月 24/25 日 | 普通礼物仍可整理；内置特别结局保持只读 |
| 12 月 26 日起 | 完整长期只读档案，保留礼物、收藏馆和邮局时间线 |

写入层按当前作者定位礼物，并校验作者归属、日期、正式封存状态和归档阶段。任何调用者均不能通过界面操作修改或删除对方礼物。写入身份由 `?writer=yan` 选择，默认三三；顶栏“偷看记名”与写入身份相互独立。

GitHub Pages 是静态站点，这些校验集中实现于浏览器数据访问层，用于保证正常客户端与实际写入 API 一致；它们不能阻止用户自行改写浏览器代码，不构成服务端秘密边界。

## 圣诞邮局

- 首页书桌显示真实活动总数、双方新增投递数、近 7 天新增、未读数、最近操作时间与安全标题提示。
- 邮局按真实操作时间倒序展示永久时间线，支持礼物日期、送礼人、操作事件、礼物类型、北京时间操作日期范围与关键词筛选，每次增量加载 30 条。
- 成功的新增、编辑、删除、附件操作、正式开启和正式封存生成事件；失败操作不生成成功事件。
- 活动记录与礼物主数据分离。删除后事件仍可保留，但不保留正文或附件。
- 未读状态排除本人操作，按作者独立保存读取游标与逐条已读 ID，支持全部已读、刷新恢复和双人同步。点击通知只跳转收藏馆对应日期，不绕过解锁。
- 混合时区时间戳按真实时刻排序；界面统一显示北京时间。

## 数据兼容与发布

- `gifts.json` 与 `sannan_gifts.json` 的名称、XOR+Base64 编码和索引文件均未改变。
- 新增本地字段全部可选；旧存档不清空、不重置。删除通过既有作者专属 tombstone 表达，不做破坏性迁移。
- 发布继续使用 GitHub Contents API、SHA 乐观并发与 409/422 重试；只有远程写入并核验成功后才本地封存和生成封存事件。
- PAT 默认仅存当前标签页 `sessionStorage`，主动选择“记住”时才明文写入该设备 `localStorage`。Token 不进入源码、礼物数据、公开仓库或日志。
- 本次交付未读取、输出、修改、重置或覆盖任何真实未揭晓礼物；代码提交与推送记录见发布文档，未改动正式线上礼物数据。

- V8 统计、主题、照片、编辑器、音乐、手账与 PAT：Chromium 45/45。
- 既有完整 E2E：52/52。
- 贴纸、导出与指南示例：Chromium/WebKit 合计 48/48。
- 音乐、预览、偷看专项：26/26。
- 显示模式、流畅模式、离线专项：24/24。
- 同步容错专项：4/4。
- Chromium 与 WebKit 响应式冒烟通过 1920×1080、1440×900、1366×768、1024×768、768×1024、744×1133、1133×744、390×844。
- 收藏馆另测 1920×1080、1366×768、1024×768、768×1024、390×844，验证桌面双栏、移动单栏、无横向溢出与 `88dvh` 高度限制。
- 已执行 JavaScript 语法检查、Python 测试编译与 `git diff --check`。

所有自动化只使用虚构或空数据及本地模拟仓库，不读取、下载、解码或打印真实礼物。WebKit 自动化不能替代真实 iPad Safari；本次未进行 iPad 实机测试。

## 部署与回滚

发布前按 `docs/release-v4.md` 复测并明确确认发布目标。网页回滚恢复前一网页提交即可；旧存档键 `advent-web-save-v1` 保持兼容，不得通过清空存档回滚，也不得为回滚删除或重置礼物仓库数据。
